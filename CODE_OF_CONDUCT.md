# Code of Conduct

We want an open, respectful and constructive community for contributors using any AI tool or none.

Be considerate and specific when discussing code, designs and people. Critique claims and evidence, not contributors' identity or AI provider. Welcome newcomers, different experience levels and resource budgets. Do not harass, discriminate, threaten, reveal private information, or publish another person's credentials, private prompts or personal data.

AI-generated comments are the submitting person's responsibility. Do not use automated agents to spam, impersonate other contributors, fabricate endorsements or overwhelm a discussion. Disclose conflicts and correct inaccurate claims promptly.

For ordinary conduct concerns, contact the repository maintainer privately through an appropriate GitHub channel rather than publishing personal details. For security vulnerabilities use [private vulnerability reporting](.github/SECURITY.md). The maintainer may moderate comments, close discussions or restrict participation when needed, and should explain actions proportionately while protecting confidentiality. This is a lightweight project policy, not a promise of 24/7 response.
