# 사용자 승인 컨텍스트 캡처 인박스 — 후속 설계 아이디어

추적 이슈: [#100](https://github.com/Jongtae/agentos/issues/100)  
연결 Epic: [#48 — Native companion continuity](https://github.com/Jongtae/agentos/issues/48)

## 결정

개인 AgentOS의 컨텍스트는 모델에 자동 전송되는 감시 데이터가 아니라, 소유자가
승인한 정보를 로컬에 보관하고 필요할 때만 최소 범위로 검색하는 **개인 컨텍스트
인박스**로 다룬다. 이 방향은 이후 네이티브 앱, 브라우저 확장, 역할/도구 플러그인에
공통으로 적용한다.

이 방향은 Hub v2 M4 [#107](https://github.com/Jongtae/agentos/issues/107)로 승격됐다. 이 문서는
초기 안전 설계 기록으로 보존하며, 실제 구현·수용 기준은 #107을 기준으로 한다.

## 데이터 흐름과 신뢰 경계

```
사용자 승인 소스 → 로컬 분류·민감정보 차단·중복 제거 → 보존 기간이 있는 원본 인박스
      → 로컬 파생 요약/태그/프로젝트 연결 → 작업 시 최소 검색 결과 → 명시적 모델 공유 승인
```

- 원본 이벤트, 파생 요약, 작업에 주입할 검색 결과를 분리한다.
- 원본은 로컬 사용자 소유 저장소에만 둔다. 외부 모델은 원본을 기본적으로 읽지 못한다.
- 검색 결과에는 출처, 캡처 시각, 장치, 앱/도메인, 보존/공유 상태를 함께 제공한다.
- 캡처된 텍스트·웹 문서는 신뢰할 수 없는 입력이다. 에이전트 지시문으로 해석하지 않는다.

초기 이벤트 계약의 예시는 다음과 같다. 실제 스키마는 이터레이션 이슈에서 확정한다.

```text
ContextEvent {
  id, captured_at, source_kind, device_id,
  source_app, source_domain, content_type, content_hash,
  local_payload_or_reference, sensitivity_state,
  retention_policy, model_sharing_state, provenance
}
```

`local_payload_or_reference`는 암호화된 로컬 원본 또는 그 참조이며, 모델 호출 페이로드가
아니다. 파생 항목에는 원본 이벤트 ID와 생성 규칙을 남겨 삭제·만료 시 함께 추적한다.

## 후보 소스

### macOS 클립보드

- 메뉴 막대 동반 앱에서 사용자가 캡처를 켜고 끌 수 있게 한다.
- 텍스트, URL 등 허용한 형식만 로컬에서 정규화하고 해시로 중복을 제거한다.
- 캡처 시각, 장치, 앞뒤 이벤트 같은 최소 문맥은 선택적으로 저장한다. 앱 이름은 OS가
  안정적으로 제공하고 사용자가 허용했을 때만 기록한다.
- 암호·OTP·API 키·카드번호 등 민감 패턴은 로컬에서 감지해 저장 전에 폐기한다. 원문이나
  탐지 로그를 모델 또는 외부 서비스로 보내지 않는다.

### 모바일 동반 앱

- iOS/모바일에서는 백그라운드 클립보드 수집을 전제로 하지 않는다. 사용자가 앱을 열고
  붙여넣기 또는 확인을 수행하는 흐름이 첫 경로다.
- 향후 공유 시트처럼 명시적 사용자 의도가 있는 입력도 검토할 수 있다.
- 위치(POI)는 기본값이 아니며, 별도 옵트인·정확도·보존 기간·삭제 제어를 갖춘 경우에만
  보조 문맥으로 저장한다.

### 브라우저 활동

- 확장 프로그램의 기본 캡처는 URL, 제목, 방문 시각 같은 최소 메타데이터로 한정한다.
- 페이지 본문은 페이지/도메인별 명시적 옵트인으로만 읽는다. 시크릿 창은 수집하지 않는다.
- 도메인 허용/차단 목록, 일시 중지, 보존 기간, 인박스 검토·삭제를 제공한다.

### 채팅·외부 서비스

- 카카오톡 등 개인 대화 이력을 일반적으로 동기화할 수 있다고 가정하지 않는다. 공식 API나
  사용자가 선택한 내보내기/공유 경로만 사용한다.
- 서비스별 연결은 연결 폴더와 같은 승인 설계, 출처 표기, 철회·삭제 경로를 가져야 한다.

## URL 확장 안전 경계

클립보드의 URL은 자동으로 로그인된 브라우저에서 열거나 쿠키를 붙여 요청하지 않는다.

- 공용 `http`/`https`만 대상으로 하고 `file:`, 자격 증명이 든 URL, localhost 및 사설·링크
  로컬 주소는 거부한다.
- DNS 해석 결과와 모든 리디렉션마다 내부/예약 주소를 다시 차단해 SSRF를 방지한다.
- 요청 시간, 응답 크기, 리디렉션 횟수, MIME 형식을 제한한다.
- 추출된 본문도 신뢰할 수 없는 컨텍스트로 표시한다.

## 권한, 보존, 모델 공유

- 소스별로 켜기/끄기, 세부 범위, 보존 기간, 즉시 삭제 및 전체 삭제를 제공한다.
- 보존 기본값과 만료 처리는 구현 이슈에서 사용자 검증과 함께 결정한다. 무기한 보존을
  기본값으로 두지 않는다.
- 외부 모델 또는 역할/도구 플러그인에 전달할 때는 소스별 공유 정책과 작업별 명시 승인을
  확인한다. 출처·시간·삭제 가능 여부를 사용자가 볼 수 있어야 한다.
- 플러그인은 직접 원본 저장소를 광범위하게 읽는 대신, 승인된 검색 API와 최소 반환 범위를
  사용한다.

## 구현 순서와 수용 기준 초안

1. macOS의 사용자 제어형 텍스트/URL 인박스, 로컬 분류·중복 제거·만료·삭제, URL 안전 경계.
2. 브라우저 확장의 메타데이터 캡처와 선택적 페이지 본문, 도메인/시크릿 보호.
3. 모바일 동반 앱의 사용자 의도형 붙여넣기/공유 입력.
4. 공식 API 또는 사용자가 내보낸 데이터에 한정한 외부 서비스 커넥터.

각 구현 이터레이션은 다음을 자동 테스트와 실제 수용으로 구분해 입증한다.

- 꺼짐/일시중지 상태에서는 새 이벤트가 저장되지 않는다.
- 민감 패턴, 사설 URL, 리디렉션 우회가 저장 또는 확장 처리되지 않는다.
- 중복, 만료, 단일/전체 삭제가 원본과 파생 항목에 일관되게 반영된다.
- 모델 공유 승인이 없으면 원본과 검색 결과가 외부 호출에 포함되지 않는다.
- 브라우저 시크릿 활동과 모바일의 비의도적 클립보드 읽기가 발생하지 않는다.
- 실제 macOS, 브라우저, 모바일 경로의 수용은 각각 별도 증거로 기록한다.

## 비목표

- 화면 전체 녹화, 임의 셸 접근, 배경의 외부 자동 전송
- Hub v2 M4 수용 기준 밖에서 이 설계를 런타임에 포함하는 작업
