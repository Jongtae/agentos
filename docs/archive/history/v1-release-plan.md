# Personal AgentOS v1 release plan

Personal AgentOS v1 is ready when a non-developer can install it on a Mac or
VPS, connect Codex or a supported model, pair a private Telegram bot, and do
personal work with clear data boundaries, recovery, backup, and restore.

| Iteration | Outcome | Acceptance evidence |
| --- | --- | --- |
| V1-01 | Guided local installation and lifecycle | Clean onboarding, safe diagnostics, restart and recovery |
| V1-02 | Telegram as daily work interface | Task state, approval, cancellation, delivery recovery after restart |
| V1-03 | Safe personal context in work | Telegram document/context source evidence and external-sharing gate |
| V1-04 | VPS operation | Clean Docker Compose install, health, backup/restore, Telegram continuity |
| V1-05 | Distribution | Clean-environment acceptance and verified release artifacts |

Native mobile clients, KakaoTalk/WeChat, a third-party marketplace, managed
hosting, and billing remain outside this release.
