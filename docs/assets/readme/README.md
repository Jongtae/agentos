# Public README visuals

The four public READMEs share the same information order and evidence boundaries. This directory contains repository-owned assets, not an external image feed. [The documentation map](../../README.md) remains the authority map.

- `interaction-model.{en,ko,ja,zh-CN}.svg`: illustrative Assistant → Computer agent → Personal AgentOS comparison. NASDAQ/NVIDIA and Amazon explain interaction, not shipped integrations.
- `presence.{en,ko,ja,zh-CN}.svg`: Owner ⇄ PA over AgentOS-owned Memory, Context, Work, Authority, Evidence and Events; Judgment orchestrates replaceable AI and tools/services. Architecture, not operating evidence.
- `hero.*.html` / `hero.*.png` and `scenes.*.html` / `scenes.*.png`: reconstructed and condensed v1 synthetic journey illustrations. The HTML is generated by [build_readme_visuals.py](../../../scripts/build_readme_visuals.py). These are not live-account screenshots. See [product status](../../product-status.en.md) and the [release manifest](../../release-manifest.json) for evidence and limits.

## Editing and visual verification

The SVGs are editable source files. Keep the same rows, layers and examples in every locale. Use explicit text rows with ordinary glyph widths; do not force text to fit with `textLength` / `spacingAndGlyphs`. The 560-unit canvas and 26–30-unit text keep the new figures readable when GitHub scales them to approximately 309 CSS pixels on GitHub’s 375-pixel viewport (254 pixels at a 320-pixel viewport). No external fonts, scripts or image resources are required; system sans-serif and CJK fallbacks render the text.

After a change:

1. Run `python3 scripts/verify_readme_localization.py` and check all README asset/link paths.
2. Open each SVG in a browser. Inspect text bounds against both its card and the viewport, including sans-serif and serif fallback. Text must not overlap another row or leave its card.
3. Inspect all four rendered GitHub READMEs at normal desktop width, 375 pixels and 320 pixels. Check each image has loaded; inspect the comparison and architecture at their actual displayed size, then read the whole README in order. A Markdown image path or successful structural check alone is insufficient.
4. Keep the comparison before release imagery, the evidence classification before the v1 panels, and the across-time conversation explicitly illustrative. Publish no owner-pilot screenshot without selected, redacted and revision-linked source evidence.

Browser screenshots and font/layout measurements prove documentation rendering only. They do not prove live AgentOS behavior.
