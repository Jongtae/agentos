연결 방식

추가할 때 선택하세요
연결 방식에 따라 무엇이 다른가요?

API는 선택한 공급자에게 요청을 보냅니다. 로컬 모델은 지정한 서버에서 실행됩니다. CLI 연결은 해당 도구의 실행 환경과 계정 설정을 따릅니다. 연결 방식과 개별 도구의 외부 전송은 별개입니다.

이 시안은 연결하거나 키를 저장하지 않습니다.

    필요할 때 확인
    프로젝트와 폴더는 어떻게 다른가요?

    폴더는 실제 파일의 위치입니다. 프로젝트는 관련 대화와 결과를 묶는 공간이며, 만들었다고 폴더 접근 권한이 생기지는 않습니다.

    내 기록

    남겨둔 내용과 작업 결과를 다시 찾습니다.

    내용종류저장

    기록을 선택하면 내용과 저장 출처를 확인할 수 있습니다.

    프로젝트

    하나의 주제에 대한 대화와 결과를 묶습니다.

    한 번의 질문은 프로젝트 없이도 할 수 있습니다.
