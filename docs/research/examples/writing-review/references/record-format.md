# Review record format

A review record is an output artifact, not a new AgentOS database.

## Brief
Document and baseline hash; owner purpose; audience; constraints; source scope; budget; actual execution mode; requested round count; publication authority.

## Finding
ID; round; reviewer perspective; severity; section; concise issue; supporting source IDs; required revision; disposition; verification note. Preserve the actual changed text/diff. Do not record hidden reasoning or invented subagent transcripts.

## Reuse decision
Requirement; candidate/source IDs; existing project seam; Adopt/Adapt/Defer; practical benefit hypothesis; exact content changed; what is not proven; next test or revisit trigger.

## Final verdict
Role; actual execution mode; content SHA-256; digest of manuscript/source/adoption/criteria bundle; PASS/REVISE/BLOCKED; gate-by-gate reasons; unresolved findings; approval scope. Both roles reference the same bundle. Changes to that bundle invalidate affected approval.

## Stop
Complete only when the actual requested review is performed and both final gates pass. When an unavailable fact, permission or budget prevents closure, retain the best draft and report the precise blocker instead of fabricating success or promising background work.
