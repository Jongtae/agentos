# Personal AgentOS — 추가 10회 검토·재작성 기록 v0.3

작성일: 2026-10-05 · 검토 차수: 11–20차 · 대상: 역할 기반 온톨로지와 위임 모델

## 결과와 승인 범위

사용자 요청의 중심은 새로움의 증명이 아니라 프로젝트에 유용한 기존 개념·실무·구현을 최대한 반영하는 것이다. v0.2와 선행 검토 보완서 v0.1을 입력으로 보존하고 **10회 추가 검토와 실제 재작성**을 수행했다. 매 차수의 완전한 원고, 실제 차이, 지적·수정 기록이 아카이브에 있다. 이전 1–10차 기록은 기존 v0.2 아카이브 그대로 함께 보존한다.

최종 편집자와 최종 검수자는 같은 v0.3 원고와 검토 묶음을 **개념 문서 출판 및 재사용 집필 콘텐츠 범위에서 승인**한다. 실행은 **단일 모델의 순차 역할 분리 검토**다. 독립된 모델·전문가·설치형 에이전트 심사를 받은 것이 아니다. 이전 v0.2의 출판 준비 승인은 F28 누락으로 보류된 역사적 기록이고, 여기서 별도로 판단했다.

## 실제 반영

역할을 관계적 역할·전문 관점·인가 역할·페르소나로 구분했다. MOISE의 역할 채택·미션 수락·목표/의무 이행 구분을 책임과 완료 설명에 조정했다. ODRL은 위임 중 정책 표현의 일부로만 매핑하며 Cedar를 실제 인가와 오류 진단의 비교 대상으로 두었다.

현재 `manifests.py`와 `skills.py`를 확인해 새로운 역할 로더 대신 기존 `SkillLibrary`/`SkillBinding`을 우선하도록 했다. 한 개 `writing-review` 텍스트 스킬과 세 개 참고 리소스를 제공하고, 이미 읽은 지침이 철회될 때의 중단·고정 버전·로딩 한도를 보존한다. 이 예제는 설치·활성화하지 않았다.

CFP의 상황·목표·대안·실행 책임·후속 범위를 분석 브리프에 조정하고 FIBO를 금융 개념의 매핑 후보로 둔다. PROV의 출처 관계를 기존 식별자와 연결하며, Solid·AgentFile 비교는 보존/변환/누락/재승인 검토로 구체화했다. 공개 평가·재작성 패턴을 참고하되 별도 프레임워크 설치나 모든 요청의 10회 검증을 요구하지 않는다.

## F28 재사용 검토 누락의 처리

**문서 출판 범위에서 해소.** 단순 참고문헌이 아니라 21개 출처와 A01–A10 적용 판단을 연결했고, 현재 코드 접점 및 채택/조정/보류 사유를 본문 3·6·9·11–15장에 반영했다. 최종 검수 V7은 선행 자료→현재 요구→적용 내용→한계→확인 방법을 검사한다. 최종 편집 E6는 독자가 지금 사용 가능한 콘텐츠와 미래 구현을 구분할 수 있는지 검사한다. 새로움이나 프레임워크 도입 개수는 승인 조건이 아니다.

## 병합 전 추가 수정 F49 — 다른 원고에 맞는 최종 기준

GitHub의 `chatgpt-codex-connector`가 남긴 [리뷰 지적](https://github.com/Jongtae/agentos/pull/1020#discussion_r4184333866)을 병합 전에 확인했다. E1/E2가 이 원고의 개인 중심 다중 역할 명제와 구성에 고정되어 있어, 다른 글에서는 관련 없는 기준을 만족해야 한다는 지적이다. 앞선 20차 검토가 이 문제를 놓쳤음을 기록한다.

E1은 입력된 핵심 명제·목적, E2는 독자·목적·원고별 구성에 맞게 일반화했다. E6도 장르의 독자 성과를 기준으로 하고, 설계 제안이 아닌 글에는 런타임 적용을 요구하지 않는다. 검토 전에 원고별 기준을 확정하며, 승인을 얻기 위해 사후에 바꾸지 않도록 했다. 아키텍처 관점과 V7 재사용 검토는 실제 제안이 있을 때 반드시 적용하고, 관련 없는 경우만 근거를 남긴다. 사실 검수는 면제하지 않는다.

페르소나 원문·스킬 리소스·개별 프롬프트를 함께 고쳤고, **8개의 추가 문서 정적 검사**와 기존 59개 검사가 통과했다. 원고와 Word 본문은 바뀌지 않았다. 다른 장르에서의 실제 에이전트 성능 실험은 아니다. 두 최종 페르소나는 수정한 기준과 새 묶음 해시를 다시 확인해 승인했다. F49 원문·수정 diff와 이전 묶음·판정은 아카이브에 보존한다.

이 지적은 실제 외부 GitHub 리뷰에서 왔지만, 전체 묶음이 독립 심사를 통과했다고 확대하지 않는다. 추가 10회와 별도로 이루어진 병합 전 수정이며, 최초 검토 기록을 소급해 고치지 않았다.

## 남은 한계

IAAP 공식 본문은 접근 실패하여 공식 검색 발췌만 범위 확인에 썼다. MOISE의 기본 문서는 읽었지만 include된 예제·API 링크 전체를 확인하거나 실행하지 않았다. AgentFile V1 SDK 문서는 legacy다. 라이브러리의 최신 릴리스별 호환성·라이선스 적합성·보안·성능 검증 및 전문 자격 판정을 수행하지 않았다.

GitHub 게시·필수 CI·병합은 이 편집 승인과 별개다. 실제 상태의 기준은 PR #1020과 그 Checks이며, 이 기록은 상태를 미리 완료로 선언하지 않는다. 현재 개발 목표·런타임·권한·공개 제품 README는 변경하지 않는다.
