Work with your files, through conversation.

AgentOS is a local-first personal agent. It keeps owner-controlled state, approvals, evidence, recovery, and a managed workspace while using bounded execution engines.

This website is information only. It is not an OAuth callback, login service, token broker, or Google Drive proxy.

What it does

AgentOS can preserve owner originals, create ordinary-file results, and reuse them in later work. Connected reference folders remain read-only by default; managed-workspace writes remain inside explicit owner scope.

Current support

Support is determined by the repository roadmap and named evidence. A website visit is never required to use a locally installed AgentOS runtime, and it does not establish a connection to Google or any other provider.
