The brain can be borrowed. The assistant should remain yours.

Personal AgentOS is an open-source environment you install on your own machine. One personal agent keeps your memory, your unfinished work, the permissions you gave it and a record of what actually ran. The AI doing the work can change.

What can change, and what stays with you

Can change

  • The CLI agent or API doing the work
  • Tools and connectors

Stays with you

  • Memory and context about you
  • Open work and its next step
  • Permissions and approvals
  • The record of what actually ran

On your Mac or Linux machine

One AI per request, swappable

  • Codex subscription
  • Claude Code subscription
  • OpenAI or Anthropic API key
  • OpenAI-compatible endpoint
  • Local Ollama model

For each request a judgment model picks the worker, writes the brief, checks the result and hands the work back when it falls short. Local-first is not local-only: with a hosted model, the context used for a request goes to that provider.

Where you already talk

Message it on Telegram from your phone, or open the local page in your browser on macOS or Linux. Windows works through WSL2, with current limitations.

It plans the route to a dinner, adds one small item to a cart and stops before payment, and tells you which step it could not check.

Boundaries it keeps

  • Only what you connect. Access starts with the folders, accounts and tools you connect. A connected folder is read-only unless you say otherwise.
  • Payment needs you, every time. Adding to a cart and paying are different actions. Each payment waits for your approval.
  • Secrets stay out. Passwords and tokens never go into a model prompt, a log or the evidence record.
  • Told, not hidden. When the AI saves something to memory it says so and offers an exact undo. Each task records which of your information it used and where it went.

Start

On macOS or Linux, one command installs and starts AgentOS. No Homebrew, Python or Docker needed.

curl -LsSf https://raw.githubusercontent.com/Jongtae/agentos/94776134546ed400ab1573d171c0bca2975a5f22/scripts/install.sh | sh

The URL pins the installer itself. Read the pinned script before you run it.

Or with Homebrew:

brew install jongtae/agentos/agentos
agentos start
  1. AgentOS opens at 127.0.0.1:8787 in your browser.
  2. Connect your AI: a subscription, an API key or a local model.
  3. Optionally pair your own Telegram bot.
  4. Ask: “I need to finish a proposal this week. Help me break it into the next few steps.”

Windows: run wsl --install, restart, open Ubuntu and run the first command there. Details in the quick start guide.
