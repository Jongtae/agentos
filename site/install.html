Install and connect

Install AgentOS from the repository on the device where it will run. Follow the repository’s current installation instructions and local runtime guidance.

Connections stay on your device

Consumers do not create a Google Cloud project, OAuth client, or token manually. If a supported connection is available, its authorization happens in the installed local runtime using the system browser and its local callback. This static site does not receive authentication codes, tokens, PKCE values, or file content.

Do not enter credentials, tokens, or personal files into this website. It has no credential form and no connection session.
