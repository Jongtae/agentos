Still. Here with you.

会話で日々のことを一緒に片づけるパーソナル AI。Still は、自分のコンピューターで動くオープンソースのアシスタント Personal AgentOS の最初の姿です。

トニー・スタークは J.A.R.V.I.S. を支える技術を自ら持っていました。私たちの多くは、モデルも価格もルールも変わり続ける提供元から、アシスタントの頭脳を借りることになります。Personal AgentOS はアシスタントをあなたの側、あなたのコンピューターに置き、その下で考える AI だけを入れ替えられるようにします。

いつでも替えられるもの

  • モデルと提供元
  • ChatGPT のプランで使う Codex、Claude のプランで使う Claude Code
  • ツールと接続

Still に残るもの

  • あなたについて知ったこと
  • やりかけの仕事と次の一歩
  • あなたが任せた権限
  • 実際に実行された記録

実際の会話を開く
  • 接続したものだけ。 選んだフォルダー・アカウント・ツールだけを使います。接続したフォルダーは、特に言わない限り読み取り専用です。
  • 支払いはあなたを待ちます。 カートに入れることと支払うことは別の操作で、すべての支払いにあなたの承認が必要です。
  • 秘密は外に。 パスワードやトークンは、モデルへのプロンプト、ログ、実行記録に入りません。

今夜、Still を迎えましょう

Mac、Linux、Windows（WSL2）のコンピューターと、いま使っている ChatGPT か Claude のサブスクリプションがあれば十分です。

  1. インストールして起動

    curl -LsSf https://raw.githubusercontent.com/Jongtae/agentos/94776134546ed400ab1573d171c0bca2975a5f22/scripts/install.sh | sh

    インストールスクリプトはアドレスでバージョンが固定されています。実行する前にスクリプトの内容を確認できます。

    Homebrew を使うなら、brew install jongtae/agentos/agentos でインストールしてから agentos start で起動することもできます。

    Windows では WSL2 の中にインストールします。PowerShell で wsl --install を実行してコンピューターを再起動し、スタートメニューから Ubuntu を開いて上のインストールコマンドを貼り付けてください。

  2. AI をつなぐ

    ChatGPT なら公式の Codex CLI にログインします（codex login）。AgentOS はそのログイン情報を見ません。Claude なら claude setup-token を実行し、表示されたトークンを一度貼り付けます。このコンピューターの資格情報ストアにだけ保存されます。そのあと 127.0.0.1:8787 で開くページで選びます。あとで替えても、Still が知っていることはそのままです。

  3. Telegram をつなぐ

    Telegram の @BotFather で自分のボットを作り（/newbot）、受け取ったトークンを 設定 → 外部接続 に貼り付けて、ペアリングリンクを開きます。これで、スマートフォンから Still と話せます。

  4. 本当の用事を一つ

    普段どおり、必要なことを聞いてみてください。たとえば「最近、猫がごはんをあまり食べない。どうしたらいい？」Still は答えながら、猫を飼っていることを自分で覚え、そのことを伝えます。数日後に「5万円以下のロボット掃除機を選んで」と言うだけで、猫の毛まで考えて選びます。

そのほかはクイックスタートガイド（英語）にあります。
