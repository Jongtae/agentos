Privacy draft

Publication requires confirmation of the legal operator, support contact, effective date, and hosting configuration. These values are intentionally not invented here.

Local AgentOS data

AgentOS is designed to retain personal state, approvals, evidence, recovery data, and managed-workspace results locally. Connected reference folders are read-only by default. Search indexes are rebuildable and separate from durable task, approval, recovery, and credential state.

Delete local data and revoke access

Local AgentOS data stays on the owner’s device until the owner removes the relevant local application data and managed-workspace material using the operating system’s file-management tools for that installation. Do not remove connected reference folders when deleting application data: that action must not delete an owner original. For a configured provider, revoke the app’s access in that provider’s account security or permissions controls; local removal and provider revocation are separate actions.

External services and control

External AI, messaging, and provider transmissions are separate policy and approval boundaries. Local storage does not mean data is never transmitted. Google authorization and Drive access, when configured, occur between the local runtime and Google; this website is not in that path.

Website data

This static site adds no analytics, credential fields, token handling, or Drive proxy. GitHub Pages and a visitor’s network provider may process ordinary web-request metadata under their own policies.

Requests

Until an operator contact is confirmed, report repository concerns through GitHub Issues.

한국어

공개 전 운영자 법적 명칭·문의처·시행일·호스팅 구성을 확인해야 하며, 이 값은 임의로 작성하지 않습니다.

AgentOS는 개인 상태·승인·근거·복구·관리 작업공간 결과를 로컬에 보관하도록 설계됩니다. 외부 AI·메신저·제공자 전송은 별도 정책·승인 경계입니다. 로컬 저장이 외부 전송이 전혀 없다는 뜻은 아닙니다.

로컬 AgentOS 자료는 소유자가 해당 설치의 운영체제 파일 관리 도구로 관련 애플리케이션 자료와 관리 작업공간 자료를 제거할 때까지 기기에 남습니다. 애플리케이션 자료를 삭제할 때 연결된 참고 폴더는 제거하지 않아야 하며, 이 작업이 사용자 원본을 삭제해서는 안 됩니다. 구성한 제공자의 권한은 해당 제공자 계정의 보안 또는 권한 제어에서 별도로 철회해야 하며, 로컬 삭제와 제공자 권한 철회는 서로 다른 작업입니다.

이 정적 사이트는 분석 도구·인증정보 입력·token 처리·Drive 프록시를 추가하지 않습니다.
