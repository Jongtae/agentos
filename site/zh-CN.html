Still. Here with you.

通过对话陪你处理日常琐事的个人 AI。Still 是 Personal AgentOS 的第一个形象，一个运行在你自己电脑上的开源助手。

你上次的咖啡豆真不错。

Still Claude Code很高兴你喜欢。埃塞俄比亚古吉，500 克，我记下了；随时可以撤销。

AI 已更换：Claude Code → Codex

你咖啡喝完了。

Still Codex上次那款埃塞俄比亚古吉 500 克已放进购物车。在你开口之前不会付款。

细心，温暖。安静，但不被动。

  • 温暖来自上下文。

    Still 会把你真正告诉它的偏好和情况用在判断里，不会假装有情绪，也不会无故夸奖。

  • 诚实体现在结果里。

    只有确认过，才会说已完成、已核实或已记住；不知道的、失败的，会单独说明。

  • 能干体现在下一步。

    与其重复状态，不如告诉你推进了什么、接下来做什么。安静不等于被动。

不必多说，它记得你说过的话。

不需要写满细节的长提示词。Still 会带上你已经说过的内容，处理繁琐的部分，并在需要你做决定的地方停下来。

大脑可以借来，Still 始终属于你。

托尼·斯塔克拥有 J.A.R.V.I.S. 背后的技术。我们大多数人则要向模型、价格和规则不断变化的提供方借用助手的大脑。Personal AgentOS 把助手留在你这一边、你的电脑上，只让底下思考的 AI 可以更换。

想换就能换

  • 模型及其提供方
  • 用 ChatGPT 订阅的 Codex，或用 Claude 订阅的 Claude Code
  • 工具和连接

留在 Still 身边

  • 它对你的了解
  • 没做完的事和下一步
  • 你交给它的权限
  • 实际执行过的记录

来自一次真实会话：购物进行到一半时从 Claude Code 换成了 Codex，Codex 在同一个购物车里接着完成了下一个请求，无需重新说明。

展开真实对话
  • 只用你连接的。 只使用你选择的文件夹、账号和工具；连接的文件夹默认只读，除非你另有说明。
  • 付款等你确认。 加入购物车和付款是两个不同的操作，每一次付款都需要你批准。
  • 密钥不外泄。 密码和令牌不会进入模型提示词、日志或执行记录。

今晚就把 Still 带回家

一台 Mac、Linux 或 Windows（WSL2）电脑，加上你已经在用的 ChatGPT 或 Claude 订阅，就够了。

  1. 安装并启动

    curl -LsSf https://raw.githubusercontent.com/Jongtae/agentos/94776134546ed400ab1573d171c0bca2975a5f22/scripts/install.sh | sh

    安装脚本的地址固定在一个版本上。运行前可以先查看脚本内容。

    如果你用 Homebrew，也可以用 brew install jongtae/agentos/agentos 安装，再用 agentos start 启动。

    Windows 上在 WSL2 里安装。在 PowerShell 中运行 wsl --install 并重启电脑，然后从开始菜单打开 Ubuntu，粘贴上面的安装命令。

  2. 连接你的 AI

    ChatGPT 用户：登录官方 Codex CLI（codex login），AgentOS 不会看到这次登录。Claude 用户：运行 claude setup-token，把生成的令牌粘贴一次，它只保存在这台电脑的凭据存储里。然后在 127.0.0.1:8787 打开的页面中选择。之后再换也没关系，Still 知道的东西都会保留。

  3. 连接 Telegram

    在 Telegram 的 @BotFather 创建你自己的机器人（/newbot），把令牌粘贴到 设置 → 外部连接，然后打开配对链接。之后就能在手机上和 Still 对话了。

  4. 交给它一件真事

    问它你真正需要的事，比如：“我家猫最近不怎么吃饭，该怎么办？”Still 在回答的同时会自己记下你养猫这件事，并告诉你它记下了。几天后只要说“帮我挑一台 3000 元以内的扫地机器人”，它就会把猫毛也考虑进去。
