    다른 연결 방법

    파일 · 저장

    AgentOS가 읽을 폴더와 결과를 남길 폴더를 관리합니다. 원본 파일은 바꾸지 않으며, 파일을 쓰지 않는 작업에는 필요하지 않습니다.

    AI가 찾아볼 폴더

    대화 중 AI가 이 폴더에서 파일을 찾아 읽습니다. 읽기만 합니다.

    실제로 있는 하위 폴더만 연결할 수 있습니다. Mac Finder에서 폴더를 선택하고 Option-Command-C를 누르면 경로가 복사됩니다.

    정리 결과 만들기

    요약·정리 작업은 원본 폴더를 읽고, 결과 저장 폴더에 새 파일로 남깁니다.

    이 설정에는 ~ 대신 /Users/… 로 시작하는 전체 경로를 입력하세요.

    원본 폴더와 겹치지 않는 폴더를 고르세요. 결과는 새 파일로만 저장합니다.
